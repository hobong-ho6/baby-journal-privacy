최종 수정일: 2026년 4월 17일

김태리 육아일지 앱은 모든 데이터를 사용자의 기기에만 저장하며, 외부 서버로 개인정보를 전송하지 않습니다. 사용자의 개인정보는 100% 안전하게 보호됩니다.

1. 개인정보처리방침 개요

김태리 육아일지 앱("이하 본 앱")은 사용자의 개인정보 보호를 최우선으로 합니다. 본 개인정보처리방침은 본 앱이 수집하는 정보와 그 사용 방법에 대해 설명합니다.

2. 수집하는 개인정보

본 앱에서 수집하는 정보는 다음과 같습니다:

  • 아기 정보: 이름, 생년월일, 성별, 프로필 사진
  • 성장 기록: 키, 몸무게, 측정 날짜, 메모
  • 음식 기록: 음식명, 재료, 섭취 날짜, 기호도, 알레르기 반응 정보
  • 사진: 아기 프로필 사진, 음식 사진

3. 개인정보 처리 목적

수집된 개인정보는 다음 목적으로만 사용됩니다:

  • 아기의 성장 기록 관리 및 분석
  • WHO 표준 기반 성장 백분위 계산
  • 음식 섭취 이력 및 알레르기 관리
  • 가족 간 육아 정보 공유

4. 개인정보 보관 및 보호

🔒 로컬 저장만 사용
모든 개인정보는 사용자의 기기에만 저장되며, 외부 서버나 클라우드로 전송되지 않습니다.
  • 저장 위치: 사용자의 iPhone/iPad 기기 내부 (UserDefaults)
  • 암호화: iOS 기본 데이터 보호 기능 적용
  • 백업: iTunes/iCloud 백업에 포함 (사용자 선택)
  • 삭제: 앱 삭제 시 모든 데이터 완전 삭제

5. 제3자 정보 제공

본 앱은 사용자의 개인정보를 제3자에게 제공하지 않습니다.

  • 광고 네트워크 연결 없음
  • 분석 도구 사용 없음
  • 외부 서비스 연동 없음
  • 데이터 판매/공유 없음

6. 사용자의 권리

사용자는 언제든지 다음 권리를 행사할 수 있습니다:

  • 열람권: 앱 내에서 모든 저장된 정보 확인
  • 수정권: 잘못된 정보 직접 수정
  • 삭제권: 개별 기록 또는 전체 데이터 삭제
  • 처리정지권: 앱 사용 중단 시 데이터 처리 자동 정지

7. 만 14세 미만 아동의 개인정보

본 앱의 특성상 만 14세 미만 아동(아기)의 정보가 포함됩니다:

  • 법정대리인(부모)의 동의 하에 정보 입력
  • 의료 목적의 필요 최소 정보만 수집
  • 외부 전송 없이 기기 내 보관

8. 개인정보처리방침 변경

본 방침이 변경될 경우:

  • 앱 업데이트를 통해 사전 공지
  • 중요한 변경사항은 별도 안내
  • 변경 사항은 공지 후 7일 후 적용

9. 문의처

개인정보 처리에 관한 문의사항이 있으시면 아래로 연락주시기 바랍니다:

  • 앱명: 김태리 육아일지
  • 개발자: Baby Journal Team
  • 이메일: privacy@baby-journal-app.com
  • 처리기한: 접수 후 7일 이내 답변
